Many people in Dhaka speak some English, but a few words of Bangla are appreciated. Spellings below are approximate.

| English | Bangla (romanised) |
| :--- | :--- |
| Hello (Muslim greeting) | Assalamu alaikum |
| Hello (Hindu greeting) | Nomoshkar |
| Thank you | Dhonnobad |
| Yes | Ji / Hyan |
| No | Na |
| How much? | Koto? |
| How are you? | Kemon achen? |
| I am fine | Bhalo achi |

## Tip

Say the price before you ride, and ask "Koto?" to check the fare. See [Rickshaws](/getting-around/rickshaws/).
